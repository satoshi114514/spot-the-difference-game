Spot the Difference: three original hand-drawn scenes — Sunny Park, Cat Café Morning and Beach at Dusk — each with seven fair-but-hidden differences. Two panels side by side, click a difference to mark it, a counter of how many remain, a 120-second timer per level, hints, score and a win screen. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Play it

```sh
node serve.ts
# open http://localhost:8080
# Click a difference · H hint · P pause · R restart
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/game, out/screenshots and out/dossier.json
```
